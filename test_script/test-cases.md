## 使用说明

- 类型：新功能验收 / 对抗 / 回归。
- 优先级：P0 阻断主流程，P1 影响重要能力，P2 影响次要或低频场景。
- 自动化状态：已有（XCTest 落地）/ 人工（GUI、输入法、VoiceOver 等无法用单测诚实覆盖）。
- 「部分」表示本轮只实现到 T1/T2，对应 AC 的完整行为要到 T3–T5 才闭合，见备注指明的所属任务。

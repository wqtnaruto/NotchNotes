# 刘海久坐提醒挂件

久坐提醒使用独立的刘海下方窗口展示鸣人风铃挂件。原有紧凑窗口继续只负责刘海点击和文件拖入；两个窗口的命中区域不重叠，避免点击挂件时展开笔记，也避免扩大透明窗口后遮挡菜单栏或其他应用。

- 提醒计时使用单调递增的系统运行时间，系统时间、时区和跨午夜变化不会导致重复或提前提醒。设置持久保存开启、挂件展示、暂停、提醒间隔和活动时长；当前轮次与倒计时不跨应用重启恢复。
- 挂件展示是独立偏好并默认关闭。关闭后，倒计时、稍后提醒、活动中和暂停状态不显示独立挂件；到点与完成反馈仍临时显示，避免隐藏外观时同时丢失提醒。笔记展开时的工具栏入口不受该偏好影响。
- 锁屏、睡眠或显示器休眠会丢弃当前轮次。恢复后从完整提醒间隔开始，不补发用户离开期间的旧提醒；手动暂停状态仍保留。
- 展开笔记或拖入文件时隐藏独立挂件并抑制自动卡片，在原工具栏提供相同状态入口。到点状态继续保留，返回收起态后最多展示一次。
- 挂件窗口不加入全屏辅助窗口集合，因此目标屏进入全屏空间时不会覆盖其他应用。普通桌面中它与笔记面板使用相同的目标屏选择规则。
- 六张状态图作为 SwiftPM 资源随应用打包，按倒计时、到点、稍后提醒、活动中、完成和暂停状态选择。图片只承载视觉状态；操作含义、倒计时和辅助技术名称始终由文本表达。
- 功能和挂件展示均默认关闭，不新增姿态检测、输入内容采集、历史统计、系统通知或声音。计时完成只表示活动倒计时结束，不推断用户实际起身。

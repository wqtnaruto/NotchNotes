# 刘海点按展开与误触修复

用户确认普通鼠标操作默认只在左键点按刘海区域时展开，同时保留主动选择悬停和文件拖入自动展开。

- 默认值与首次升级均切到点按；通过一次性迁移标记确保后续手动选择不会被启动逻辑覆盖。仅修改默认值无法覆盖已保存的旧悬停设置。
- 普通触发、透明窗口和提示范围统一使用刘海宽高，避免收起面板高度比物理刘海更大时在下沿之外命中。无刘海屏幕保留既有模拟入口。
- 文件拖入独立保留原有收起面板高度加 28 点的范围。拖拽剪贴板内容可能残留，轮询仅接受相对上次结束状态发生变化的文件拖拽，避免普通按下复用旧文件数据。
- 本地和全局点击入口共用命中策略；读取事件自身的位置，全局事件在异步派发前保存坐标，避免以随后鼠标位置重新判定历史点击。
- 不改变展开后的收起、标题编辑确认门控和笔记数据；偏好存储支持注入，测试使用独立 suite，避免修改用户实际设置。

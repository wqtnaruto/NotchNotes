# NotchNotes 产品需求：分页标题双击编辑

## 一、产品定位与整体说明

### 1.1 业务目标

让管理多篇笔记的用户直接看见各分页的用途，并能独立命名，不必为了改变分页标题而改写笔记正文。

### 1.2 输入与证据边界

| 来源 | 已确认事实或结论 | 证据边界 |
|---|---|---|
| 用户原始诉求 | 每个分页均可双击编辑其标题 | 已确认需求意图 |
| 用户交互选择 | 将分页圆点改为常显文字标签，双击文字就地编辑 | 已确认，不采用双击圆点弹窗方案 |
| 用户配套规则确认 | Enter 或点击别处保存，Esc 取消，空标题恢复自动标题，允许重名，最多 50 个字符，单行横向滚动，编辑期间避免自动收起 | 已确认产品规则 |
| 现有应用与测试 | 分页当前以圆点展示，悬停显示自动标题；支持新建、切换、删除和恢复最近删除的分页；至少保留一个分页 | 来自当前代码及已有测试，不等同于新功能已实现 |
| 现有标题规则 | 正文首个非空行经现有 Markdown 前缀处理后生成标题；无可用结果时使用本地化的“无标题 序号” | 本次保留自动标题逻辑 |
| 现有面板交互 | Esc 会收起面板，面板也可能按鼠标位置自动收起 | 与标题编辑的退出行为存在交互冲突，按第五章处理 |
| 用户项目管理说明 | NotchNotes 是个人项目，不需要创建 Meegle 工作项 | 需求在本地文档中确认，不以 Meegle 关联或工作项号作为前置条件 |

产品判断：在多分页场景下，常显标题和独立命名有助于辨认内容。尚无使用频率、查找耗时或误操作率数据，不设未经验证的量化收益承诺。

本项目直接以用户确认的本地 PRD 推进后续规格、计划与开发，不创建 Meegle 工作项，也不执行需求描述回写或远端状态流转。本文件是供评审的产品设计，不代表完成研发或通过产品验收。

### 1.3 用户与场景

- 用户：在本机使用 NotchNotes 管理多篇笔记的人；本功能不新增账号或角色。
- 场景示例：用户同时记录会议事项和临时待办，希望把一页命名为“周会”，但保留正文原样。
- 当前成本：需要逐页切换或悬停辨认；独立标题不可编辑，只能依赖正文生成的名称。
- 成功标准：用户可以直接从文字标签辨认分页，并通过双击完成独立命名；修改不改变正文，重新打开应用后标题仍保留。

### 1.4 模块与流程

模块链条：分页栏展示 → 选择目标分页 → 标题就地编辑 → 校验与确认 → 本地保存 → 标题展示更新。

涉及分页栏、标题编辑、笔记本地保存及面板交互；文件暂存、防休眠、Markdown 正文编辑不新增能力。

### 1.5 范围与非目标

**提供：** 常显文字标签、单击切换、双击原位改名、清空恢复自动标题、保存与取消、长标题展示、分页溢出访问、老数据兼容及基本键盘/辅助技术访问。

**不提供：** 独立改名页面、正文首行同步改写、批量重命名、分页排序、分组、搜索、云同步、导入导出、标题历史版本或新的权限体系。

**保持：** 分页身份和顺序、正文及已有正文选区、新建与删除入口、最近删除恢复、至少一个分页、应用整体面板尺寸与文件暂存能力。只有标题编辑进行中时，覆盖原有 Esc 和自动收起行为；编辑结束后恢复原规则。

## 二、业务术语说明

| 术语 | 业务含义 |
|---|---|
| 分页 | 一篇独立笔记，不是表格列表的翻页页码 |
| 分页栏 | 展示分页文字标签及新建入口的导航区域 |
| 文字标签 | 分页栏中的可点击标题，代替现有圆点 |
| 自定义标题 | 用户明确保存的名称，与正文相互独立 |
| 自动标题 | 未设置自定义标题时，按现有规则从正文或默认名称生成的标题 |
| 有效标题 | 最终用于标签、悬停说明和辅助技术读出的名称；按第六章确定 |
| 编辑草稿 | 本次标题输入的临时内容，成功保存前不替换已保存标题 |
| 就地编辑 | 在原标签位置切换为单行输入框，不跳转页面或弹出独立改名窗口 |
| 浏览态 / 编辑态 / 校验失败态 / 保存失败态 | 标题区域的四种交互状态，详见第五章 |
| 清空标题 | 移除自定义标题，恢复自动标题；不删除分页或正文 |
| 删除分页 | 沿用现有删除操作，将分页从正常笔记集合移除；保留现有最近删除恢复能力，不等同于清空标题 |

## 三、模型关系

关系清单：

- 本机笔记集合 **1:N** 分页，N 至少为 1。
- 分页 **1:1** 正文，正文允许为空。
- 分页 **1:0..1** 自定义标题。
- 分页 **1:1** 有效标题，有效标题始终由第六章规则生成。
- 全部分页共享一个标题编辑交互：同时最多编辑一个分页；编辑草稿为临时交互数据，不是新建的独立笔记。

关键关系：

1. 标题依附分页身份，不用标题文本识别分页，重名不会合并内容。
2. 保存或清空自定义标题都不改变正文、分页顺序或分页身份。
3. 自定义标题不存在时，正文变化可影响有效标题；存在时，正文变化不覆盖用户命名。
4. 删除及恢复分页时，已保存自定义标题与正文一同移除或恢复，未保存草稿不进入恢复内容。
5. 横向归属为当前本机笔记集合；没有新增组织、租户、跨账号共享或外部系统归属。

本功能没有多对多关系、业务明细子表或中间业务对象。

## 四、数据模型

### 4.1 类型与控件白名单

- 字段类型：**标识、文本**。不在本产品设计中指定代码类型、存储结构或数据库字段。
- 控件词汇：**单行输入框、只读文本、文字标签、按钮、悬停说明、单行滚动区域、正文编辑区域**。
- 标识 → 只读且不直接展示；自定义标题 → 单行输入框；正文 → 现有正文编辑区域，保持原交互；有效标题 → 文字标签及悬停说明。
- 公共参数：跟随应用语言提供说明，可键盘访问且焦点可辨认。标题输入框的特有参数为单行、自动聚焦、进入时全选、完整值可查看与编辑。

### 4.2 分页——承载一篇笔记及其可独立修改的名称

以下列出本需求涉及的业务字段；其他既有字段保持原含义，不新增审计、排序或权限字段。

| 名称 | 类型 | 规则 | 描述 | 备注 |
|---|---|---|---|---|
| 分页标识 | 标识 | 必填；在本机笔记集合内唯一 | 确定标题属于哪篇笔记 | 沿用既有生成规则，创建后不可改；不供用户输入 |
| 正文 | 文本 | 选填；不要求唯一 | 分页已有笔记内容，也是自动标题的来源 | 沿用已有内容与长度规则，标题操作不可修改 |
| 自定义标题 | 文本 | 选填；不要求唯一 | 用户给分页独立设置的名称 | 统一适用第四章标题输入规则，无值表示使用自动标题 |
| 有效标题 | 文本 | 必填；不要求唯一；只读 | 分页对用户显示的最终名称 | 由第六章计算，不单独保存；标签视觉省略不改变有效标题 |

### 4.3 标题输入规则

以下为标题输入的唯一规则来源，其他章节引用本节：

1. **规范化：** 输入为纯文本。粘贴的换行、制表符按连续段转为一个普通空格，再去除首尾空白；内部普通空格保留。Markdown 符号在自定义标题中按普通文字呈现。
2. **长度：** 规范化后非空名称最多 50 个用户可见字符；中文、英文字母及完整组合表情各按一个可见字符计数，不按字节计算。
3. **空值：** 空字符串或只有空白的内容表示清除自定义标题，不报“必填”错误；有效标题立即按第六章回退。
4. **重名：** 允许不同分页使用相同名称，不自动追加序号，不改变分页身份。
5. **超长：** 保留草稿并提示错误，不自动截断、不覆盖原名称；缩短后可以重试。
6. **无变更：** 非空草稿经规范化后与进入编辑时的有效标题一致，视为无变更。原本没有自定义标题的分页不得因此固定为自定义标题；空草稿统一按第 3 条处理。
7. **展示和输入分离：** 输入框加载完整有效标题，不把标签因空间不足显示的省略号当作输入值。自动标题自身已有的截取规则仍保留，不在本次扩展。

### 4.4 字段属性卡：十三维度

| 维度 | 分页标识 | 正文 | 自定义标题 | 有效标题 |
|---|---|---|---|---|
| 1. 身份标识 | 唯一定位分页；沿用现有业务标识，不新增接口字段名 | 分页的现有内容字段，无独立业务编码 | 分页的命名属性，无独立业务编码；实现字段名不在此定义 | 分页的展示结果，无独立业务编码 |
| 2. 数据类型 | 标识 | 文本 | 文本 | 文本 |
| 3. 业务归类 | 身份 | 内容 | 命名 | 展示 |
| 4. 必填与默认 | 系统必填并生成 | 选填，沿用新页空正文 | 选填；新页及无该属性的老数据默认为无值 | 必须有值；跟随标题解析结果 |
| 5. 校验规则 | 集合内唯一且不可修改 | 标题操作不增加正文校验 | 按 4.3；错误统一引用 5.5 | 只读，按第六章产生非空结果 |
| 6. 取值来源 | 系统生成 | 现有正文输入 | 用户输入；无远端搜索、字典或接口选项 | 自定义标题、自动标题或本地化默认名称 |
| 7. 前端控件 | 不直接展示，无输入控件 | 正文编辑区域，保持原样 | 单行输入框；自动聚焦并全选 | 文字标签、悬停说明；单行展示 |
| 8. 联动角色 | 标题归属条件 | 未命名时是标题计算条件 | 标题解析的优先条件 | 联动计算结果 |
| 9. 状态与生命周期 | 随分页创建、删除、恢复 | 随分页存续 | 无值/有值；随保存、清空、分页删除及恢复变化 | 随依赖字段重新计算；无独立启停 |
| 10. 多语言与审计 | 不翻译、不新增审计展示 | 不自动翻译、不新增审计 | 用户内容不自动翻译；新增提示跟随应用语言；不新增更新人或时间展示 | 默认名称沿用应用本地化；不新增审计展示 |
| 11. 存储与配置 | 沿用既有本地保存 | 沿用既有本地保存 | 作为分页属性本地持久保存；固定产品字段，不做配置平台 | 仅展示不单独保存 |
| 12. 去向与归档 | 本机分页集合，无新增下游 | 本机原分页，不由标题操作写入 | 原分页；正常退出重开仍保留；不发往外部系统 | 分页栏、悬停说明、辅助技术名称；无归档映射 |
| 13. 安全与敏感 | 继承本机访问边界 | 内容可能敏感，标题操作不外传 | 名称可能敏感；本地保存且不新增上报、加密或共享机制 | 与原分页可见性一致；不新增跨用户访问 |

### 4.5 字段场景差异矩阵

本表中的“编辑”特指标题编辑，不指正文编辑。“导入”全部不可填，因为本功能不提供导入入口。

| 字段 | 新增 | 编辑 | 导入 | 查看 |
|---|---|---|---|---|
| 分页标识 | 不可填 | 不可填 | 不可填 | 隐藏 |
| 正文 | 不可填 | 不可填 | 不可填 | 只读 |
| 自定义标题 | 不可填 | 选填 | 不可填 | 只读 |
| 有效标题 | 不可填 | 只读 | 不可填 | 只读 |

新增分页沿用原入口，初始不增加标题必填步骤。编辑完成后回到现有正文编辑流程，正文可编辑能力不受本表限制。

### 4.6 字段联动角色

| 字段 | 角色（条件/结果） | 联动类型 | 说明 |
|---|---|---|---|
| 分页标识 | 条件 | 归属 | 确定当前输入只影响哪个分页 |
| 自定义标题 | 条件 | 计算 | 是否有值决定采用手动名称还是自动标题 |
| 正文 | 条件 | 计算 | 仅在自定义标题无值时参与生成 |
| 有效标题 | 结果 | 显示 | 第六章计算后同步到标签、悬停说明及辅助技术名称 |

不新增条件必填、选择字典、远端联动、业务明细行、加密字段或跨系统归档。分页最小数量沿用现有至少一个；不为本需求新增分页数量上限。

## 五、操作规范

### 5.1 六类操作及四要素

| 操作 | 输入字段及填写口径 | 前置约束 | 成功后动作 | 批量支持 |
|---|---|---|---|---|
| 新建分页 | 不输入自定义标题；沿用现有新建入口 | 应用展开；存在标题草稿时先按 5.3 结束编辑 | 新页无自定义标题，选中新页并显示其有效标题 | 不支持批量 |
| 编辑标题 | 分页标识为目标；标题输入按 4.3 | 分页存在且可见，整个窗口同时至多一个标题输入框 | 成功保存后更新原分页名称；正文、标识与顺序不变 | 不支持批量 |
| 启用停用 | 不适用，无输入字段 | 不适用；分页没有标题启停状态 | 不适用；清空标题是恢复自动标题，不是停用 | 不支持 |
| 删除分页 | 目标分页标识 | 沿用现有右键删除入口，至少保留一个分页；目标存在 | 从正常集合移除正文和已保存自定义标题，并沿用最近删除恢复能力 | 不新增批量 |
| 导入 | 不适用，无导入字段 | 本需求无导入入口 | 不适用；无唯一性识别、增改判定或空字段覆盖语义 | 不支持 |
| 导出 | 不适用，无导出字段 | 本需求无导出入口 | 不适用；不新增标题或笔记导出 | 不支持 |

创建后不可由标题操作修改的字段：分页标识、正文，以及原有创建信息、分页顺序和正文选区。仅自定义标题属于本次可写入业务属性。

删除方式沿用原行为：不是新增逻辑删除状态，而是从正常本地分页集合移除，并保留当前会话中最近一次删除的恢复内容；本需求不新增回收站、保留期限或跨重启恢复承诺。恢复时已保存自定义标题必须与正文一并恢复。

### 5.2 页面与操作显隐

本需求只涉及现有展开面板中的分页栏和原位标题输入框，不新增业务页面。

| 操作 | 显示条件 | 隐藏条件或不显示说明 | 是否二次确认 |
|---|---|---|---|
| 文字标签浏览与单击切换 | 面板展开；对应分页存在 | 面板收起时不展示分页栏 | 否 |
| 双击标题进入编辑 | 标签可见；其他标题草稿已按 5.3 处理 | 不提供批量编辑或独立弹窗 | 否 |
| 标题单行输入框 | 该分页处于标题编辑或失败状态 | 浏览态隐藏 | 否 |
| 新建“＋” | 面板展开，固定在分页栏一端 | 面板收起时隐藏；不随标签滚动移出视野 | 否 |
| 删除分页 | 沿用右键菜单；只剩一页时保留禁用状态 | 不新增标签上的关闭按钮 | 沿用现有无二次确认行为 |
| 清空自定义标题 | 在标题输入框中清空后确认 | 不新增独立按钮 | 否 |
| 辅助技术重命名动作 | 可访问的分页标签获得焦点 | 不新增页面，与双击使用相同流程 | 否 |

### 5.3 状态与动作矩阵

| 状态 | 可用按钮（操作） | 备注（含跳转目标、角色差异） |
|---|---|---|
| 浏览态 | 单击切换；双击改名；新建；右键删除；滚动标签 | 双击未选中页时先选中目标，再在其标签处编辑；所有本机用户行为一致 |
| 编辑态 | 输入、选择、复制粘贴、Enter 保存、Esc 取消、点击别处确认 | 输入框加载完整有效标题并全选；原正文选区不得被标题选区覆盖 |
| 校验失败态 | 修改草稿后重试，或 Esc 取消 | 原标题不变；应用内切换、新建和另一页编辑暂不执行，直到保存成功或取消；删除当前目标按 5.4 |
| 保存失败态 | 保留草稿，Enter 重试，Esc 取消 | 不显示已保存成功；不覆盖原持久标题；应用内其他跳转与校验失败态相同 |

通用退出规则：

- **Enter：** 无输入法组字时按 4.3 校验并保存，成功后回到该页浏览态，正文选区保持。未修改即确认按无变更处理。
- **Esc：** 无输入法组字时仅取消当前标题编辑并恢复原有效标题，本次按键不收起面板；随后再次按 Esc 恢复原收起行为。
- **点击输入框外：** 先校验并尝试保存，成功后执行原点击动作；在应用内点击另一个分页、新建入口等均遵循该顺序。失败时保留草稿，不继续应用内跳转。
- **系统失焦：** 切到其他应用也尝试保存；若失败，保留草稿和失败状态，不强行抢回系统焦点，用户返回后可修改或取消。
- **同时改多页：** 双击另一页前先结束当前草稿；前者失败时不新开第二个编辑框，不将草稿串写到另一页。

### 5.4 边界与兼容规则

- **布局溢出：** 分页栏为单行横向滚动区域，不自动换行挤占正文；标签过长时在视觉上省略，悬停说明展示完整有效标题。切换、新建及进入编辑时，目标标签自动滚入可见区域。“＋”固定可见。
- **面板行为：** 标题编辑及失败状态期间，单纯鼠标移出不能自动收起面板，延迟聚焦也不能把键盘焦点抢回正文；退出编辑后恢复现有规则。
- **输入法：** 中文等输入法正在组字时，Enter 优先确认候选，Esc 优先取消组字，不提前保存或退出标题编辑；组字结束后再按相应键执行标题操作。
- **重复操作：** 编辑中再次双击同一输入框执行正常文字选择，不重置草稿；重复确认不创建分页或重复写入命名结果。
- **目标删除：** 用户从现有菜单删除正在改名的分页时，删除优先，丢弃未保存草稿，沿用分页删除规则；恢复时使用删除前最后保存的标题。目标因其他操作不存在时引用错误清单，不新建同名页补救。
- **新页与老数据：** 无自定义标题时都使用自动标题，不新增启动补填或迁移确认；已存在的笔记正文、标识、顺序与选区保持。
- **恢复：** 删除再恢复分页，名称和正文保持对应，不把其他页的标题带入。
- **正常退出与重启：** 已确认保存的自定义标题必须保留；仍在编辑的标题先按同一规则尝试保存，失败时要求用户修改或取消后再正常退出。不新增崩溃或强制退出后的草稿恢复能力。
- **多语言：** 用户标题原文保持；默认名称和新增交互提示跟随应用的中英文设置，分页顺序和归属不因语言切换变化。
- **旧客户端边界：** 新应用读取无自定义标题的历史数据必须兼容；不承诺旧应用再次保存后仍保留新增命名信息。本需求不安排客户端降级的数据同步能力。

### 5.5 统一校验与错误提示

下列标识仅用于产品提示追踪，不是新增接口错误码；错误文案不在其他章节另行定义。

| 提示标识 | 触发与校验时点 | 文案（中文 / 英文） | 用户恢复路径 |
|---|---|---|---|
| TITLE_TOO_LONG | 输入法组字结束后或确认保存时，按 4.3 计算超长 | 标题最多 50 个字符，请缩短后重试。 / Titles can contain up to 50 characters. Shorten the title and try again. | 保留原名称与输入草稿，缩短后再次确认 |
| TITLE_SAVE_FAILED | 尝试确认标题但无法完成本地保存 | 标题未保存，请重试或按 Esc 取消。 / Title wasn't saved. Try again or press Esc to cancel. | 保留草稿，重试或取消；不误报成功 |
| TITLE_TARGET_MISSING | 确认保存前发现目标分页不存在，且不是用户刚执行的删除 | 该分页已不存在，未保存标题。 / This note no longer exists. The title wasn't saved. | 结束本次编辑，显示仍存在的分页，不隐式新建 |

空值与重名是合法输入，不新增必填或重名错误。

## 六、匹配与渲染逻辑

### 6.1 入参

目标分页标识、对应分页已保存的自定义标题、正文、现有分页序号、应用语言及分页栏可用空间。没有组织筛选、远端查询或额外权限参数。

### 6.2 逐级过滤

1. 先确认目标分页存在；不存在时不可保存，按第五章处理。
2. 只读取目标分页自身数据，禁止按标题文本查找或去重分页。
3. 未保存的草稿仅在输入框展示，不参与其他位置的有效标题解析；成功提交后才替换已保存的自定义标题。
4. 无值的自定义标题不参与优先命中，转入自动标题逻辑。

### 6.3 优先级排序

1. 有自定义标题：使用其已保存的完整名称。
2. 没有自定义标题：沿用现有自动标题生成规则，从正文第一个非空行提取并处理已有 Markdown 前缀；现有自动标题超过 42 字符时使用前 41 字符加省略号的规则保持不变。
3. 自动标题没有可用内容：使用应用当前语言的默认名称与现有分页序号，例如“无标题 2”或“Untitled 2”。

这是同一分页内的命名优先顺序，不涉及分页重新排序；标题相同时仍按各自身份和原顺序展示。

### 6.4 返回与过滤

- 生成一个非空有效标题，供标签、悬停说明与辅助技术名称共用。
- 标签按可用空间单行展示，必要时进行视觉省略；不因视觉省略改写自定义标题。
- 编辑框及悬停说明使用完整有效标题；自动标题既有的截取属于其现有命名规则，与标签空间省略区分。
- 当前页具有可辨认的选中态，编辑框具有可辨认的焦点；单行滚动区域内不丢失目标标签或固定新建入口。
- 用户文本作为普通文字展示，不新增 Markdown 渲染、外部链接导航或内容上报。

### B.1.4 成功标准与评估口径

发布验收以 B.5.9 的可观测行为为准：提醒可达、操作可理解、计时结果一致、正常工作不被抢焦点、关闭后完全停止。

试用时观察用户能否独立完成“开启—理解提醒—开始活动—返回工作”，以及是否频繁跳过或关闭。可经自愿试用反馈记录“已展示提醒中开始活动的比例”和“因打扰而停用的原因”；活动计时结束不等于用户真实起身。本需求不新增后台埋点、用户追踪或虚构量化收益目标。

## 二、业务术语说明

| 术语 | 业务含义 |
|---|---|
| 久坐提醒 | 功能名称；按时间发出活动邀请，不检测坐姿 |
| 挂件 | 依附刘海下缘的可爱角色及状态入口 |
| 提醒间隔 | 每轮开始到首次到点提醒之间的可计入时长 |
| 活动计时 | 用户主动开始的一段短倒计时，不证明用户实际活动 |
| 提醒轮次 | 从一轮开始到跳过、活动计时结束或被中断的单次过程 |
| 待处理 | 已到提醒时间，等待用户选择；可显示卡片或静态提示 |
| 稍后提醒 | 同一轮中延后一次提醒，不创建第二轮 |
| 跳过本次 | 结束当前轮次，立即开始完整的新提醒间隔，不计为活动 |
| 暂停 | 用户暂时停止所有计时与提醒，保留配置，需主动恢复 |
| 停用 | 关闭功能并隐藏挂件，保留已保存配置 |
| 等待解锁 | 因锁屏、睡眠或显示器关闭而停止当前轮次，恢复可用后重新开始 |

## 三、模型关系

关系清单：本机应用设置 1:1 久坐提醒配置；久坐提醒配置 1:0..1 当前提醒轮次；当前提醒轮次 1:0..1 提醒卡片；挂件与卡片只是当前状态的展示，不形成独立历史记录。

1. 所有对象归属于当前 macOS 用户的本地应用数据，不归属于某个笔记分页。
2. 同时最多一份配置、一个当前轮次和一张提醒卡片；切换屏幕或语言不能复制轮次。
3. 配置在正常重启后保留；轮次只在当前应用运行期间有效，不补发退出期间的提醒。
4. 功能关闭、锁屏或退出时丢弃当前轮次；不影响笔记、文件暂存或防休眠状态。
5. 不建立活动历史对象、明细子表或多对多关系，无额外明细行初始化与数量约束。

## 四、数据模型

本节类型白名单：开关、整数、枚举、时长、标识。控件白名单：开关、单选项、按钮、只读文本。时长统一以秒表达业务精度；设置选项以分钟显示。

### B.4.1 久坐提醒配置

用途：保存用户对提醒节奏的选择。默认建议见【待确认1】。

| 名称 | 类型 | 规则 | 描述 | 备注 |
|---|---|---|---|---|
| 功能开启 | 开关 | 必填；无需唯一；默认关闭 | 决定是否运行及显示挂件 | 用户通过开关修改；关闭保留其余配置 |
| 提醒间隔 | 整数 | 必填；无需唯一；默认 45；只允许 30、45、60、90 | 下一轮首次提醒的等待分钟数 | 固定单选项，不提供任意文本输入 |
| 活动时长 | 整数 | 必填；无需唯一；默认 2；只允许 1、2、3、5 | 下一次活动计时的分钟数 | 固定单选项 |
| 手动暂停 | 开关 | 必填；无需唯一；默认否；停用时清为否 | 持久保存用户主动暂停的意图 | 由暂停/恢复按钮更新，无独立设置开关；关闭状态不可为是 |

固定产品参数：稍后提醒为 5 分钟，每轮最多一次；自动展开卡片展示 12 秒；完成反馈展示 3 秒。上述值不在设置中暴露，不因语言或屏幕改变。

### B.4.2 当前提醒轮次

用途：维持一个正在进行的提醒过程；仅在内存中有效，不持久化为用户活动记录。

| 名称 | 类型 | 规则 | 描述 | 备注 |
|---|---|---|---|---|
| 轮次标识 | 标识 | 存在轮次时必填；当前运行会话内唯一 | 区分旧提醒与当前提醒 | 系统生成，创建后不可改，不在界面显示 |
| 当前阶段 | 枚举 | 必填；无需唯一 | 取值：倒计时、待处理、稍后提醒、活动中 | 初始倒计时；无轮次时由全局状态展示关闭、暂停或等待解锁 |
| 本轮间隔 | 时长 | 必填；无需唯一；由本轮创建时的配置生成 | 当前轮次的提醒间隔快照 | 创建后不可改，用户设置新值仅影响后续轮次 |
| 剩余时长 | 时长 | 条件必填；无需唯一；最小为 0 | 倒计时、稍后提醒或活动中的剩余时长 | 待处理阶段无值，不显示负数；系统更新 |
| 已使用稍后提醒 | 开关 | 必填；无需唯一；初始否 | 控制本轮是否还可以延后 | 延后一次即为是，不因收起卡片重置 |
| 本次活动时长 | 时长 | 活动中必填，其余无值；无需唯一 | 开始活动时读取配置作为快照 | 活动中修改设置不影响本次计时 |

## 五、操作规范

### B.5.1 页面与入口

| 页面或触点 | 展示内容与职责 |
|---|---|
| 现有设置菜单 → 久坐提醒 | 打开轻量设置面板，展示开启、提醒间隔、活动时长、暂停/恢复、预览提醒 |
| 刘海下缘挂件 | 平时显示角色；悬停显示当前状态；单击打开当前状态卡片 |
| 提醒卡片 | 角色、短文案、对应状态的时间和操作，最多一张 |
| 活动计时卡片 | 活动剩余时长、温和活动邀请和“结束计时”；收起后挂件保留状态 |

首次安装与已有用户升级均默认关闭，不自动弹出引导。开启即生效，不增加账号、通知授权或系统管理员授权步骤。

### B.5.2 六类操作及四要素

| 操作 | 输入字段及填写口径 | 前置约束 | 成功后动作 | 批量支持 |
|---|---|---|---|---|
| 新建配置/轮次 | 配置取默认值；轮次字段由系统生成 | 首次使用配置；开启且可运行时生成轮次 | 展示配置；新轮次从完整间隔开始 | 不支持 |
| 编辑配置 | 提醒间隔、活动时长按 B.4.1 单选 | 设置面板可操作 | 单项保存；按 B.4.5 生效；失败恢复原值 | 不支持 |
| 启用/停用 | 功能开启开关 | 本机应用运行 | 启用时创建轮次；停用立即移除轮次与所有提醒展示 | 不支持 |
| 删除 | 无用户输入；系统丢弃结束或中断轮次 | 跳过、结束、关闭、锁屏或退出 | 物理移除运行对象；无历史与级联笔记删除；配置无独立删除入口 | 不支持 |
| 导入 | 不适用，无入口 | 不适用 | 不适用，无唯一键匹配、增改或空值覆盖语义 | 不支持 |
| 导出 | 不适用，无入口 | 不适用 | 不适用，不导出配置或活动记录 | 不支持 |

创建后不可由用户修改：轮次标识、当前阶段、本轮间隔、剩余时长、已使用稍后提醒、本次活动时长；用户仅通过下表动作推进状态。本功能无业务单据、复制、提交、审批或归档操作，操作×模型写入矩阵与下游集成不适用。

### B.5.3 状态与动作矩阵

| 状态 | 可用按钮（操作） | 备注（含跳转目标、角色差异） |
|---|---|---|
| 关闭 | 开启、编辑配置、预览提醒 | 挂件不显示；只能从设置进入，所有本机操作同一权限 |
| 倒计时 | 立即活动、暂停提醒、打开设置、收起 | 立即活动结束等待并进入活动中，不必等到点 |
| 待处理 | 起来活动、5 分钟后提醒、跳过本次、暂停提醒、收起 | 稍后提醒仅本轮未使用时显示；收起不等于跳过 |
| 稍后提醒 | 立即活动、跳过本次、暂停提醒、收起 | 不提供再次延后，剩余归零后重新进入待处理 |
| 活动中 | 结束计时、暂停提醒、收起 | “结束计时”提前结束并开始新轮次，不显示完成祝贺 |
| 暂停 | 恢复提醒、编辑配置、预览提醒 | 原轮次已丢弃；手动恢复时从完整间隔开始 |
| 等待解锁 | 无可见操作 | 恢复可用后按 B.5.5 处理，不在锁屏上展示 |
| 完成反馈（展示状态） | 收起 | 活动计时到点时短暂展示；业务上已进入新轮次，无待确认阻塞 |

所有状态均可从设置停用；开启状态下“暂停提醒”丢弃原轮次并关闭卡片，显示静止的睡眠鸣人风铃。暂停持续到用户手动恢复；正常退出重开后仍暂停。停用后再次启用解除暂停。全局状态的初始值为关闭。

### B.5.4 提醒与计时规则

1. 应用运行、功能开启、未手动暂停且屏幕可用时计时；不要求笔记窗口展开或应用在前台。无输入行为也继续计时，不据此推断离席。
2. 提醒间隔归零后进入待处理；在可展示时风铃自动摆动一次并展开卡片。卡片自动收起后保留静态提示，不反复弹出、不闪烁、不播放声音。
3. 用户鼠标在卡片内或键盘焦点已进入卡片时停止自动收起；离开后重新计算展示时长。用户主动打开的卡片仅在点击外部、明确收起或 Esc 时关闭。
4. “5 分钟后提醒”从点击时刻开始倒计时；到点允许本轮第二次且最后一次自动展示。两次到点均被忽略后，仍保留待处理，直到用户采取动作；不会自动创建新轮次或累计欠下的提醒。
5. “起来活动”立即开始活动计时并收起到小挂件，用户可再次点击查看秒级剩余时长。计时期间不触发另一轮提醒。
6. 活动计时归零时自动开始完整新轮次；在允许展示时播放一次完成反馈。文案只说明计时结束，不声称检测到用户站立。
7. “跳过本次”及“结束计时”立即开始完整新轮次；没有惩罚、积分扣除或二次确认。重复点击同一旧卡片按钮只执行一次。
8. 保存新的提醒间隔对下一轮生效；新的活动时长对下一次开始活动生效。设置面板明确标示该生效时点，不静默重置正在运行的时间。
9. 倒计时以经过时长为依据；手动修改系统时间、跨午夜或时区变化不能导致提前提醒、延后整小时或重复提醒。界面隐藏后再次打开须显示正确的剩余时长。

### B.5.5 休眠、重启与异常边界

| 场景 | 预期行为 |
|---|---|
| 锁屏、系统睡眠、所有显示器关闭 | 立即隐藏并丢弃当前轮次；活动中被中断也不记为完成；进入等待解锁 |
| 恢复显示且已解锁 | 开启且未手动暂停则从完整提醒间隔重新开始；不补发离开期间提醒。短暂锁屏也按同一规则重置 |
| 用户手动暂停后经历锁屏/唤醒 | 保持暂停，不能自动恢复 |
| 应用正常退出或崩溃后重开 | 保留开启、暂停及用户配置；未暂停且可运行时从完整间隔开始；不恢复旧活动计时或旧卡片 |
| 防休眠已开启 | 不自动关闭防休眠；只依据实际锁屏、睡眠或显示可用状态处理。用户需自行选择暂停提醒 |
| 当前屏幕拔出、切换或缩放 | 挂件跟随应用目标屏重新定位，轮次和剩余时间保持；无可用显示器按等待解锁规则处理 |
| 旧用户首次加载、配置部分缺失 | 缺失字段补默认；没有新功能开启记录时视为关闭 |
| 配置无法读取或值非法 | 功能安全停用，不自动恢复提醒；设置中提示并允许“恢复提醒默认设置”；用户触发后保存完整默认配置 |
| 配置保存失败 | 保留原已保存值并展示错误，原提醒节奏继续；若停用保存失败，本次运行仍立即停止，提示重启后可能恢复 |
| 多个事件同时发生 | 停用、手动暂停、锁屏优先于到点、完成反馈和旧卡片动作；被终止轮次的后续事件忽略 |

“手动暂停”的字段定义见 B.4.1。暂停或恢复保存失败时不提交动作，维持原状态并允许重试；停用保存失败是例外，当前运行立即停止。开启功能时若屏幕不可用，先进入等待解锁，不创建运行轮次。

| 倒计时 | 风铃竖直静止，鸣人睁眼微笑 | 距离下次活动还有 32 分钟 / Next break in 32 min |

| 稍后提醒 | 风铃轻摆，鸣人闭眼微笑，铃罩旁显示小钟挂牌 | 好呀，5 分钟后再叫你 / Okay, I’ll remind you in 5 min |
| 活动中 | 鸣人做侧身伸展，吊牌下方配进度弧与剩余时间 | 离开屏幕，轻松活动一下 / Step away and move a little |
| 完成反馈 | 风铃轻弹，鸣人眯眼举起双手 | 活动计时结束，按自己的节奏继续吧 / Break timer finished. Carry on at your own pace. |
| 暂停 | 风铃竖直静止，鸣人闭眼小睡，铃罩旁显示暂停挂牌 | 我先休息，准备好再叫我 / Paused. Resume when you’re ready. |

布局建议：紧凑风铃宽约 32 pt、高约 72 pt；到点状态允许摆动包围框扩展至宽约 72 pt、高约 96 pt；提醒卡片宽约 300 pt，按内容自适应高。挂绳锚定刘海下缘，完整铃罩、鸣人吊牌和垂片必须在刘海遮挡区之外可见，不覆盖菜单栏文字、摄像头区域或原有刘海点击区域；显示器空间不足时优先保证文字与按钮完整，挂件可等比缩小。按钮目标区域建议至少 28×28 pt。

动画规则：一次提醒摆动/伸展约 0.3–0.6 秒，风铃围绕顶部挂点往返一次后回到垂直静止；完成反馈最多持续 B.4.1 约定时长；平时不做持续摆动、闪光或全屏动效。系统“减少动态效果”开启时改为静态姿势与淡入淡出，所有状态都能通过文字辨识。倒计时小于 1 分钟显示“不到 1 分钟”；活动计时使用“分:秒”。不展示负值或以“你已久坐 X 分钟”冒充检测结果。

主按钮为“起来活动 / Take a break”；次按钮为“5 分钟后提醒 / Remind in 5 min”；“跳过本次 / Skip this time”为轻量文字操作。完整英文、较长中文、深浅桌面背景及系统缩放均需验证，不用裁切隐藏主操作。

### B.5.7 显隐、避让与可访问性

| 操作或展示 | 显示条件 | 隐藏条件或不显示说明 | 是否二次确认 |
|---|---|---|---|
| 紧凑挂件 | 已开启、屏幕可用，笔记面板收起 | 停用、锁屏、无屏幕；笔记展开时替换为面板内状态入口 | 否 |
| 自动提醒卡片 | 到点且笔记收起、无文件拖入、无设置交互、非全屏应用占用目标屏 | 受抑制时仅标记待处理，不抢焦点；恢复可展示后补一次当前轮提醒 | 否 |
| 面板内状态入口 | 笔记展开且已开启 | 笔记收起后回到刘海挂件；只使用固定小图标，不插入正文或挤动分页栏 | 否 |
| 主动打开状态卡片 | 点击挂件/面板内状态入口，或键盘激活等价入口 | 点击外部或 Esc 收起；显式打开可绕过自动展示抑制 | 否 |
| 稍后提醒 | 待处理且本轮未使用稍后提醒 | 活动中、稍后提醒中、已使用时均不显示 | 否 |
| 暂停/恢复 | 开启时按当前暂停状态二选一 | 停用时隐藏 | 否 |
| 预览提醒 | 设置面板打开 | 关闭设置时结束；采用预览标识，不修改真实轮次 | 否 |

自动提醒绝不激活应用、夺取键盘焦点、选中笔记内容或阻断点击。点角色只打开状态卡片，点原刘海区域沿用现有笔记触发行为；两者命中范围不得重叠。悬停模式下，鼠标移入角色不应误打开笔记。文件拖放路径优先，卡片与挂件不截获文件投放。

打开笔记、开始文件拖入或进入目标屏全屏应用时，当前自动卡片收起；已经展示过的机会不自动重播。未曾展示的待处理提醒在限制解除后只补一次，不排队补发多个提醒。全屏期间挂件也隐藏，计时继续；主动从应用入口打开仍可处理待处理状态。会议和屏幕共享不自动识别，用户使用暂停控制；该范围提案见【待确认3】。

“预览提醒”在设置内显示隔离的示例卡片，标注“预览，不影响当前计时”；示例按钮不改变真实轮次，预览期间真实计时继续，到点按设置交互抑制规则处理。

键盘可从设置或面板状态入口打开卡片，Tab 依序访问操作，Enter/Space 激活，Esc 仅关闭当前卡片并回到原入口。只有用户主动进入卡片时才转移焦点。VoiceOver 可读角色功能、当前阶段、剩余时间和按钮；不每秒播报倒计时。所有状态均含文字或图标区别，不只靠颜色。

## 六、匹配与渲染逻辑

### B.6.1 入参

功能开启、手动暂停标记、当前轮次与剩余时长、屏幕锁定/可用状态、目标屏全屏状态、笔记展开和文件拖入状态、设置交互状态、应用语言、系统减少动态效果偏好及可用展示空间。

### B.6.2 逐级过滤

1. 功能关闭：不返回挂件和卡片；保留设置入口。
2. 锁屏或无可用显示：不返回可见内容，按 B.5.5 终止轮次。
3. 手动暂停：返回暂停角色；不生成到点事件。
4. 目标屏全屏：抑制自动展示，继续计时；主动打开按 B.5.7 处理。
5. 笔记展开、文件拖入或设置交互：抑制自动卡片，保留适用的状态入口；数据状态继续变化。
6. 无抑制且待处理尚未展示：返回本轮唯一提醒卡片；曾展示则仅返回静态挂件。

### B.6.3 优先级排序

行为冲突优先级为：停用 → 手动暂停 → 锁屏/睡眠 → 用户有效操作 → 计时到点 → 装饰反馈。同一轮的开始活动或跳过成功后，其他旧卡片动作无效。

视觉优先级为：用户正在进行的笔记/拖放/设置操作 → 用户主动打开的状态卡片 → 到点提醒 → 完成反馈 → 普通陪伴。完成反馈受抑制则直接省略，不在很久以后补播。屏幕选择沿用 B.1.2，不按鼠标位置复制挂件。

### B.6.4 返回与过滤

返回一个角色姿态、可读状态、适用的剩余时间及操作集合。移除当前状态不允许的按钮；无可用屏幕时返回空展示，但设置与业务状态保持按规则处理。所有内容使用应用当前语言，角色和状态不因语言切换重置。

卡片与挂件不包含笔记内容、文件名或用户输入；长文案按空间换行，主操作不可挤出屏幕。自动展示与用户主动打开共享同一轮次，关闭展示不等于完成或跳过。

## 七、通用规则汇总

### B.7.1 编码规则一览

| 对象 | 编码规则 | 唯一性范围 | 生成方式 |
|---|---|---|---|

### B.7.2 状态机汇总

| 对象 | 状态值 | 流转规则 |
|---|---|---|
| 功能控制 | 关闭、运行、暂停、等待解锁 | 初始关闭；开启进入运行；暂停需主动恢复；锁屏进入等待解锁，恢复规则见 B.5.5；任意状态可停用 |
| 当前提醒轮次 | 倒计时、待处理、稍后提醒、活动中 | 倒计时到点进入待处理；待处理可延后一次或开始活动；延后到点回待处理；跳过或活动结束创建下一轮；中断移除轮次 |
| 卡片展示 | 隐藏、显示、预览 | 自动展示受 B.5.7 约束；收起只改变展示；预览与真实状态隔离 |

“等待解锁”也涵盖无可用显示器的等待。手动暂停意图与显示可用性分别保留：暂停期间锁屏仍隐藏所有展示，解锁后恢复暂停外观，不启动计时。

### B.7.3 删除约束汇总

| 对象 | 删除方式 | 前置约束 | 联动删除 |
|---|---|---|---|

| 轮次 | 物理移除运行数据，无历史保留 | 结束、跳过、暂停、停用、锁屏或退出 | 撤销旧卡片及其动作 |
| 展示卡片 | 收起展示，不等于删除轮次 | 关闭动作、展示超时或被其他交互抑制 | 无 |
